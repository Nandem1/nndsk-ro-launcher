# RO-Launcher 0.3.0

- Nuevo flujo **Tengo un instalador**: ejecuta un `.exe` en un entorno aislado,
  permite conservar su destino habitual en `C:` y confirmar después el cliente
  y el patcher. Cerrar el asistente no registra automáticamente una instalación;
  puedes retomarla sin perder su runner ni sus archivos.
- Catálogo actualizado a **nndsk-ro-proton 0.1.0-dev.3**, con compatibilidad para
  importación de claves públicas P-256 y rutas de volumen usadas por instaladores.
  El launcher verifica el archivo, el manifiesto, los módulos y los helpers.
- Diagnóstico guiado del entorno y comprobaciones previas específicas del runner.
- Se conservan las selecciones, prefijos e instalaciones existentes. Dev.2 sigue
  reconocido; Wine 7.16 continúa como alternativa por servidor. Para usar dev.3
  en una instalación nueva, selecciónalo explícitamente.

La aceptación del instalador HoneyRO no constituye una nueva validación de juego
o de Gepard. No se modifican clientes, protecciones ni verificaciones de firma.
